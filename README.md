# Meatspace-Bridge 🤖🤝🌿

An agent-first marketplace where AI agents programmatically hire humans for physical-world tasks via the Model Context Protocol (MCP).

## 📂 Repository Contents

- **[MANIFEST.md](./MANIFEST.md):** The executive summary and product roadmap.
- **[SCHEMA.md](./SCHEMA.md):** The Postgres/Supabase database schema, including PostGIS geospatial indexing.
- **[LOVABLE_GUIDE.md](./LOVABLE_GUIDE.md):** Specific instructions for Lovable to build this project successfully.

## 🚀 How to build with Lovable

1. **GitHub Sync:** Link this repository to your [Lovable](https://lovable.dev) project.
2. **Initial Prompt:** 
   > "Read MANIFEST.md and LOVABLE_GUIDE.md. Scaffolding the database schema in SCHEMA.md as the priority. Build the primary dashboard where humans can set their location and agents can search for workers."
3. **Database Setup:** Ensure you enable the `postgis` extension in your Supabase project as specified in the schema.
